# 15 · Карточка лота: полная опись элементов

Этот файл существует потому, что при перерисовке карточку **дважды упростили** и
потеряли то, что уже работало: грейд A+/A/A−/B/D с кнопкой «i», карусель фото,
число ставок, зачёркнутую розничную, состояния молотка.

**Правило: любой новый эскиз карточки проверяется по этому списку до показа.**
Если элемент не нарисован — либо он есть, либо рядом написано, почему его убрали.
Молча выкидывать нельзя.

Источник истины — `apps/web/src/components/LotCard.tsx`. Ниже всё, что там есть,
с адресами.

## Поля, которых в движке ещё нет

`LotCard.tsx:22-27` размечает их опциональными, чтобы блок появился сам, как
только API начнёт их отдавать:

- `retailCents` — зачёркнутая цена и процент скидки
- `gradeCode` — грейд A+/A/A−/B/D
- `packaging` — второй чип состояния
- `hot` — тег «Karsts»

**В эскизах их рисуем всегда** — иначе при подключении полей окажется, что для
них нет места в вёрстке.

---

## Как проверять новый эскиз

1. Открыть этот файл.
2. Пройти 31 строку сверху вниз.
3. Каждый ненарисованный элемент — либо вернуть, либо написать под эскизом, почему
   его нет.
4. Эскизы состояний: обычный, «ты лидируешь», «тебя перебили», последние секунды,
   продано. Экраны `w01`–`w04`.

Одной картинки «карточка» недостаточно: половина элементов видна только в
определённом состоянии, и именно они теряются первыми.
