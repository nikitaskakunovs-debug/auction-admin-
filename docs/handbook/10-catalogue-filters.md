# 10 · Фильтры каталога

Утверждено 17.08.2026. Переработка `apps/web/src/components/Catalogue.tsx`
и фильтровых блоков в `globals.css`.

Мобильный — приоритет: 80 % трафика с телефона.

---

## 1. Что было не так

Не вёрстка. Пять дефектов в самой модели фильтров.

1. **Одно состояние в четырёх местах.** `coll` менялся из ряда подборок,
   из чипа «Kolekcija» в панели и из секции шторки. Плюс ряд активных чипов
   показывал то же самое в четвёртый раз.
2. **Два фильтра с одинаковым результатом.** `when = "1h"` и
   `quick.includes("closing")` оба сводились к `left(a) > 3_600`. Пользователь
   ставил один, потом второй, и ничего не менялось.
3. **`Kārtot` на телефоне открывал шторку фильтров.** Обе кнопки `.fbar-mob`
   вызывали `setSheet(true)`.
4. **Двойной ползунок цены.** `PRICE_MAX = 1_000_000`, `PRICE_STEP = 10_000` —
   сто шагов на трек ~350 px, то есть **3,5 px на шаг**. Пальцем не берётся;
   два ползунка на одном треке ещё и перекрывают друг друга.
5. **Семь секций шторки подряд** — около 2600 px прокрутки на экране 390 px,
   причём первой шла сортировка, которая фильтром не является.

Плюс счётчики были только у категорий, поэтому по остальным вариантам
пользователь попадал в пустую выдачу.

## 2. Новая модель

Три уровня, у каждого своя роль и свой вид. Один уровень — одно место.

| Уровень | Что это | Где | Вид |
|---|---|---|---|
| **Подборки** | навигация по кураторским наборам | ряд `.hrail` под шапкой | `.chip` |
| **Тип лота** | режим, не фильтр | в `.page-head` справа (веб), под подборками (телефон) | `.seg` |
| **Фильтры** | сужение выдачи | `.fbar` (веб) / одна шторка (телефон) | `.fchip` + `.pop` |
| **Сортировка** | порядок, не фильтр | за `.fdiv` справа | отдельный `.pop` / отдельная шторка |

### Состав фильтров — четыре плюс «Papildus»

| Фильтр | Значения |
|---|---|
| Kategorija | все 12 категорий движка, со счётчиками |
| Cena | 4 пресета + два поля «no – līdz» |
| Stāvoklis | 16 состояний движка, множественный выбор |
| Beidzas | Jebkad · Tuvākajā stundā · Šodien · 3 dienās |
| **Papildus** | переключатели: без резервной цены · горячие |

Убрано:

- чип **«Kolekcija»** — это и есть ряд подборок;
- группа **«Rādīt tikai»** — `closing` слит в «Beidzas», `nores` и `hot` стали
  переключателями в «Papildus»;
- ряд **активных чипов на вебе** — состояние уже написано на самих чипах
  панели. На телефоне ряд остаётся, там панели нет.

## 3. Цена: пресеты и два поля

Двойного ползунка больше нет.

```
[ līdz 50 €  1 ] [ 50–200 €  2 ] [ 200–2000 €  6 ] [ no 2000 €  2 ]
[     200     ] – [     2000    ]
```

- Пресеты пересчитываются под текущую выдачу и показывают счётчики.
- Поля `inputmode="numeric"`, значения в евро, в состоянии — центы.
- Ввод в поле снимает выделение с пресета; выбор пресета подставляет значения
  в поля.
- Класс `.pricepick`.

---

## 4. Счётчики и нулевые варианты

У **каждого** варианта каждого фильтра стоит число — сколько лотов останется,
если его выбрать, с учётом остальных активных фильтров.

Вариант с нулём **не скрывается**, а получает `aria-disabled="true"` и
`opacity:.38`. Скрытие заставляет список прыгать под пальцем.

## 5. Шторка на телефоне — аккордеон

```
Filtri                                        Atlasīti 6 no 11
─────────────────────────────────────────────────────────────
Kategorija                                     Pulksteņi   ⌄
Cena                                        200 – 2000 €   ⌃
   [пресеты + два поля]
Stāvoklis                                        Jebkurš   ⌄
Beidzas                                          Jebkad    ⌄
Papildus                                              —    ⌄
─────────────────────────────────────────────────────────────
[ Notīrīt ]            [ Rādīt 6 lotus ]
```

- Классы `.acc`, `.acc-i`, `.acc-i.open`, `.acc-h`, `.acc-b`.
- Свёрнутый заголовок показывает текущее значение; выставленное — `.v.set`
  (цвет `--text`, вес 700), пустое — `--text-3`.
- Открыта одна секция. Открытие второй закрывает первую.
- Кнопка внизу показывает результат живьём: `Rādīt {n} lotus`.
- Сортировки в этой шторке **нет** — у неё своя.

```
H1 Visi aktīvie loti                                [ Visi 11 | Izsole 8 | Pērc 3 ]
11 loti · atjaunojas reāllaikā

[ Visi ] [ Augstvērtīgie ] [ Noliktavu atlikumi ] [ Mantojums ]

[ Kategorija Visas ⌄ ][ Cena Jebkura ⌄ ][ Stāvoklis Jebkurš ⌄ ][ Beidzas Jebkad ⌄ ][ ⚙ Papildus ]   │ [ Kārtot Drīzāk beidzas ⌄ ]
```

Один ряд, не восемь чипов в два ряда. Сортировка отделена `.fdiv` и уведена
вправо через `margin-left:auto`.

## 7. URL

Фильтры пишутся в querystring — сейчас этого нет, состояние теряется при
перезагрузке и ссылкой не делится.

```
/katalogs?coll=highvalue&type=auction&cat=watches&min=20000&max=200000
         &cond=new,openbox&ends=today&only=nores&sort=ending
```

- `replaceState` при каждом изменении, без перерисовки страницы.
- Значения по умолчанию в URL не пишутся.
- Чтение при монтировании — как сейчас через `useSearchParams`, но по всем
  ключам, а не только `category`, `closing`, `reserve`, `q`.
